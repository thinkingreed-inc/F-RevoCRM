# TS-10 フロントエンド（React Web コンポーネント）

対象: `assets/react-web-components/src/components/`

| コンポーネント | 役割 |
|---|---|
| `Documents/DocumentsPage.tsx` | 一覧画面の親。フォルダ・フィルタ・検索・表示切替を保持 |
| `Documents/DocumentsFolderTree.tsx` | フォルダツリー |
| `Documents/DocumentsListView.tsx` / `DocumentsGridView.tsx` | 一覧（リスト／グリッド） |
| `Documents/DocumentsPreviewPanel.tsx` / `DocumentsPreviewView.tsx` / `FilePreviewRenderer.tsx` | プレビュー |
| `Documents/DocumentCreateEditModal.tsx` | 登録・編集モーダル |
| `Documents/DocumentDetailModal.tsx` | 詳細モーダル |
| `Documents/ComplianceHistoryModal.tsx` | 変更履歴・監査ログ |
| `Documents/DocumentsRelatedList.tsx` | 他モジュールの関連リスト |
| `Documents/DocumentSelectModal.tsx` | 既存ドキュメントの紐づけモーダル（**TS-13** に集約） |
| `Documents/DocumentsUploadZone.tsx` | ドラッグ＆ドロップ領域 |
| `Documents/FolderDialog.tsx` | フォルダ作成・編集・権限設定 |
| `Documents/StarButton.tsx` / `FileIcon.tsx` | 部品 |
| `Documents/hooks/*` | データ取得・状態管理 |
| `Holidays/**` / `DocumentsCompliance/**` | 設定画面（TS-02 / TS-04 に記載） |

テスト方針: **振る舞い**をテストする。要素の取得は role / ラベル / テキストを優先し、
CSS クラスや DOM 構造に依存しない。API は fetch の直モックではなく
ネットワーク層（MSW 等）でモックし、4xx / 5xx / タイムアウト / 不正 JSON も返す。

## 1. 期待される振る舞い（仕様）

| # | 仕様 |
|---|---|
| S-01 | 各画面は「ローディング」「成功」「エラー」「空」「権限なし」の5状態を表示し分ける |
| S-02 | 一覧はフォルダ・検索・電帳法フィルタ・ソート・ページングを組み合わせて絞り込める |
| S-03 | 表示形式（リスト／グリッド）を切り替えられ、選択が保持される |
| S-04 | ドラッグ＆ドロップでファイルを登録できる（常に分割アップロードを使用） |
| S-05 | 登録モーダル内のドロップは一覧側のドロップ処理へ**伝播させない**（二重登録を防ぐ） |
| S-06 | アップロード進捗を `%` 表示する（`%` が重複しない） |
| S-07 | 保存・削除などの破壊的操作は確認を挟み、実行中は二重送信できない |
| S-08 | サーバーのエラーメッセージを画面に表示する（無言で失敗しない） |
| S-09 | 文言は翻訳キー経由で表示し、キーがそのまま画面に出ない |
| S-10 | 一覧の再読込は前のリクエストを中断する（古い応答で上書きしない） |
