## 1. 期待される振る舞い（仕様）

### 1.1 適合チェック

| # | 仕様 |
|---|---|
| S-01 | 書類区分（`document_category`）が設定されているドキュメントのみ電帳法の対象。<br>**NULL と空文字はどちらも「対象外」**として扱い、抽出条件・件数集計でも同じ判定にする |
| S-02 | 対象外のドキュメントは適合状態を持たない（`status = null`）。<br>一括チェックでは適合・不適合のどちらにも数えず、`skipped` に計上する |
| S-03 | **書類区分ごとに定めた取引モジュール**に1件も関連付けが無い場合、不適合<br>（例: 契約書は `ServiceContracts`、請求書は `Invoice`/`SalesOrder`/`PurchaseOrder`/`Accounts`/`Vendors`） |
| S-03b | 判定対象のモジュールは設定画面から書類区分ごとに変更できる（TS-04）。未設定の区分は既定値を使う |
| S-03c | 対象モジュールを1つも選ばない書類区分は、関連付けを適合の条件にしない |
| S-04 | 内部ファイル（`filelocationtype = 'I'`）でファイルハッシュが未登録なら不適合 |
| S-05 | 保存区分（`preservation_type`）が未設定なら不適合 |
| S-06 | スキャナ保存で解像度が 200dpi 未満なら不適合。**未入力（空・NULL）は 0dpi として扱い不適合**とする |
| S-06b | 解像度が数値として解釈できない場合は `InvalidArgumentException`。API では保存前に弾く |
| S-06c | 一括チェックでは、1件の値が不正でも全体を止めず、その件を不適合として数える |
| S-07 | 不適合理由は**翻訳キーのまま**保存し、表示時に現在の言語へ翻訳する |
| S-08 | 問題が1件も無ければ `compliant`、1件でもあれば `non_compliant` |
| S-09 | チェック実行時に `compliance_checked_at` を更新する |
| S-09b | `compliance_status` は**判定を実行した時点の結果**を保存する。<br>判定基準（書類区分ごとの取引モジュール）を変更しても、既存ドキュメントは自動では再判定されない（後述の運用手順を参照） |

### 1.1.1 運用手順: 判定基準を変更したときの再判定（S-09b）

適合状態は保存された値を表示するため、基準を変えただけでは画面の表示は変わらない。
**判定基準を変更したら、必ず再判定を実行する**こと。

| # | 手順 |
|---|---|
| 1 | 設定 > システム構成 > 電子帳簿保存法設定 で「取引レコードの判定」を変更し、保存する |
| 2 | 同じ画面の「**適合状態を再判定**」を実行する（確認ダイアログ → 対象/適合/不適合の件数が表示される） |
| 3 | ドキュメント一覧の電帳法フィルタ（適合状態）で、想定どおりに変化したかを確認する |

- 手順2を省略すると、一覧・詳細の「不適合」表示が**古い基準のまま**残る。
- 対象件数が多い環境では手順2に時間がかかるため、業務時間外に実施する。
- 次の操作では**その場で自動的に再判定**されるため、手順2は不要:
  - 適合情報の保存（`ComplianceAPI mode=save_compliance` / ドキュメントの保存）
  - 取引レコードとの関連付けの追加・解除（`RelationAPI`。TS-13）
  - マイグレーション `20260806111640_add_compliance_transaction_modules` の適用時（初回のみ）

## 3. 境界値・同値分割

### BV-1: `scan_resolution_dpi`

| 入力 | 期待 |
|---|---|
| `null` / `''` / 空白のみ | 0 として扱う → **不適合**（`LBL_ISSUE_LOW_SCAN_RESOLUTION`） |
| `0` | 不適合 |
| `1` | 不適合 |
| `199` | 不適合（境界） |
| `200` | 適合（境界） |

| `' 300 '` | trim して 300 → 適合 |
| `-1` | 不適合 |
| `'abc'` / `'300dpi'` / `'1.5'` | `InvalidArgumentException`（API では保存前に弾く） |

### BV-2: `document_category`

| 入力 | 期待 |
|---|---|
| `null` | 対象外（`status = null`）。一括チェック・レポート・一覧フィルタの対象に含まれない |

### BV-2b: 書類区分ごとの取引モジュール設定（`compliance_transaction_modules`）

| DB の値 | 期待 |
|---|---|

| `''` / `'abc'`（JSON でない） | 同上（既定へフォールバック） |
