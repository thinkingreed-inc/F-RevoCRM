# TS-04 リンクの開き方

対象:

- ウィジェット `<shared-links-widget>`（`SharedLinksWidget.tsx`）と、リンクを開く処理 `utils/openSharedLink.ts`
- ウィジェットに渡すデータ（`Home_SharedLinks_Dashboard`、`SharedLinksContents.tpl`）

Vitest は `openSharedLink.test.ts`（window.open・フォームを差し替えて確かめる）と `SharedLinksWidget.test.tsx`（表示とクリックの受け渡し）。

## 1. 期待される振る舞い（仕様）

| # | 仕様 | 仕様書 |
|---|---|---|
| S-01 | リンクは設定した開き方（別タブ / 別ウィンドウ）で開く。CRM の画面そのものは遷移しない | 3.3 |
| S-02 | GET の `<a>` の href には、パラメータを付けた最終的な URL を入れる | 3.3 |
| S-03 | GET・別タブはブラウザの通常の動き（`target="_blank"`）に任せる | 3.3 |
| S-04 | GET・別ウィンドウは、通常のクリックだけを JS で受けて `window.open` で開く。中クリック・Ctrl / Shift / Alt / ⌘＋クリックはブラウザに任せる | 3.3 |
| S-05 | POST は押したときに JS でフォームを作って送信し、送信後にフォームを消す。HTML に `<form>` を書き出さない | 3.3, 6.2 |
| S-06 | POST・別ウィンドウは、先に指定サイズの空のウィンドウを開き、そのウィンドウの文書の中でフォームを作って送る（CRM の画面から `target=名前` で送ると、`rel` を付けた場合にブラウザが新しいタブで送ってしまう）。中を操作できなければ `rel` なしで `target=名前` で送る。送信直後に開いたウィンドウの `opener` を外す | 3.3 |
| S-07 | 別ウィンドウは今のウィンドウの中央に開く。画面より大きいサイズは画面に収める | 3.3 |
| S-08 | ウィンドウの名前は `frSharedLink_<リンク ID>` で固定（同じリンクは同じウィンドウを使い回す） | 3.3 |
| S-09 | POST でポップアップがブロックされたら通知し、送信しない | 3.3 |
| S-10 | リファラーを送らない設定なら、`<a>` の rel・`window.open` の features・フォームの rel に `noreferrer` を付ける。オフなら付けない（`noopener` は常に付ける） | 5 |
| S-11 | POST で CRM の CSRF トークン（`__vtrftk`）をリンク先へ送らない | 6.2 |
| S-12 | タイトル・説明・URL・送信内容は HTML エスケープして出力する | 6.3 |
| S-13 | CSP の `form-action` は `'self'` に `$csp_allowed_domains['form-action']` を足したもの | 6.5 |
| S-14 | POST の送り先が `form-action` で許可されていなければ、ウィジェットはウィンドウを開かずに通知する | 3.3, 6.5 |
| S-15 | ウィジェットの行に vtiger の共通 CSS（`.group` の margin）が効かない | 3.2 |

## 2. デシジョン表

### DT-1: クリックしたときの動き

| 条件 | R1 | R2 | R3 | R4 | R5 | R6 |
|---|---|---|---|---|---|---|
| メソッド | GET | GET | GET | POST | POST | POST |
| 開き方 | tab | window | window | tab | window | window |
| クリック | * | 通常 | 中 / 修飾キー付き | * | * | * |
| ポップアップ | * | * | * | * | 開けた | ブロック |
| **既定の動作を止める** | − | ✓ | − | ✓ | ✓ | ✓ |
| **window.open** | − | URL を名前・サイズ付きで | − | − | `about:blank` を名前・サイズ付きで | 呼ぶが null |
| **フォームを送信** | − | − | − | target=`_blank` | target=ウィンドウ名 | − |
| **通知** | − | − | − | − | − | ポップアップのブロック |
| ケース | TC-OPN-001 | TC-OPN-002 | TC-OPN-003 | TC-OPN-004 | TC-OPN-005 | TC-OPN-006 |

### DT-2: リファラー

| メソッド・開き方 | noreferrer オフ | noreferrer オン | ケース |
|---|---|---|---|
| GET・別タブ（`<a rel>`） | `noopener` | `noopener noreferrer` | TC-OPN-010 / 011 |
| GET・別ウィンドウ（features） | `…,noopener` | `…,noopener,noreferrer` | TC-OPN-012 / 013 |
| POST・別タブ（フォームの rel） | `noopener` | `noopener noreferrer` | TC-OPN-014 / 015 |
| POST・別ウィンドウ（ポップアップの文書） | meta なし | `<meta name="referrer" content="no-referrer">` | TC-OPN-015 |
| 実ブラウザでリンク先が受け取る Referer | CRM のオリジン（パスなし） | なし | TC-OPN-016 / 017 |

### DT-3: 別ウィンドウのサイズ

### DT-4: POST と CSP（form-action）

| 条件 | R1 | R2 | R3 |
|---|---|---|---|
| メソッド | GET | POST | POST |
| 送り先が `form-action` で許可されている | * | ✓ | − |

### DT-5: form-action のソース表現との照合（`Rules::isFormActionAllowed`）

| ソース | 送り先 `https://kintai.example.com/login` | ケース |

| `https://*.example.com` | 可（`https://example.com/` は不可） | TC-OPN-053 |
