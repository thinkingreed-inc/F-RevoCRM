# TS-02 公開範囲の判定

対象:

- `Settings_SharedLinks_Rules_Model::isVisible()`（DB を使わない判定）
- `Settings_SharedLinks_Module_Model::getVisibleLinksForCurrentUser()`（実際のユーザーの権限情報を使う）
- ダッシュボードのウィジェット（実際にログインしたユーザーに見えるか）

## 1. 期待される振る舞い（仕様）

| # | 仕様 | 仕様書 |
|---|---|---|
| S-01 | 公開範囲が「全員」なら、すべてのユーザーに表示する | 3.4 |
| S-02 | 「指定した対象のみ」なら、対象のどれか 1 つに当てはまれば表示する（OR） | 3.4 |
| S-03 | ユーザー: 見ているユーザー本人なら当てはまる | 3.4 |
| S-04 | グループ: 属していれば当てはまる。グループの中のグループ・役割経由で属している場合も含む（共有ルールと同じ `GetUserGroups` で DB から求める） | 3.4 |
| S-04b | 役割とグループは権限ファイルではなく DB から求める（管理者の権限ファイルは役割の経路とグループを持たないため） | 3.4 |
| S-05 | 役割: 見ているユーザーの役割と同じなら当てはまる。上位・下位・兄弟の役割は当てはまらない | 3.4 |
| S-06 | 役割と下位: 見ているユーザーの役割がその役割と同じか、その下位なら当てはまる。上位・兄弟は当てはまらない | 3.4 |
| S-07 | 削除された役割・グループ・ユーザーには誰も当てはまらない | 3.4 |
| S-08 | 無効なリンクは、公開範囲に関係なく表示しない | 3.1 |
| S-09 | 管理者も同じ判定に従う | 3.4 |
| S-10 | 公開範囲外のリンクは、URL・パラメータも HTML に出さない | 6.4 |
| S-11 | 想定外の公開範囲・種類は「当てはまらない」として扱う | 6.1 |
