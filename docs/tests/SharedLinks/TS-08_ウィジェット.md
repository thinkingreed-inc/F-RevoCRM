# TS-08 ウィジェット（リンクのまとまり）

対象:

- `Settings_SharedLinks_Module_Model`（`getSets` / `saveSet` / `deleteSet` / `isWidgetTitleTaken` / `getVisibleLinksForCurrentUser`）
- `Settings_SharedLinks_Rules_Model::validateWidgetTitle()`、画面の `validateWidgetTitle()`
- API（`save_set` / `delete_set` / `list` の `sets` / `save` の `set_id`）
- 管理画面のタブ（`SharedLinkSets.tsx`）、編集モーダルの「ウィジェット」
- 「ウィジェットの追加」メニュー（`SharedLinksWidget.js`）

## 1. 期待される振る舞い（仕様）

| # | 仕様 | 仕様書 |
|---|---|---|
| S-01 | 管理者はウィジェットを複数作れる。作ると「ウィジェットの追加」メニューに見出しで出る（`vtiger_links` に 1 行） | 3.1, 7.0 |
| S-02 | 見出しは必須・30 文字まで・`< > & " '` は使えない・ほかのダッシュボードウィジェットと同じ名前（大文字小文字を区別しない）は付けられない。自分の今の見出しのままの保存はできる | 3.1 |
| S-03 | 見出しを変えると、メニューと各ユーザーのウィジェットの見出しが変わる。置いたウィジェットは残る（`linkid` は変えない） | 3.1, 7.0 |
| S-04 | ウィジェットを削除すると、中のリンク（パラメータ・対象）・メニューの項目・各ユーザーの配置も消える。ほかのウィジェットのリンクは残る | 3.1, 7.0 |
| S-05 | リンクはどれか 1 つのウィジェットに属する。編集でほかのウィジェットへ移せる | 3.1 |
| S-06 | ダッシュボードのウィジェットには、そのウィジェットのリンクだけを出す | 3.2 |
| S-07 | 1 つのタブに同じウィジェットは 1 個まで。ほかのウィジェットは、1 つ置いた後も（再読み込みしなくても）メニューから選べる | 3.2 |
| S-08 | ウィジェットが無いときは案内を出し、リンクは追加できない | 3.1 |
| S-09 | ウィジェットが 1 つも無い環境でマイグレーションを流すと、最初のウィジェット「共有リンク」を作る | 7.4 |
