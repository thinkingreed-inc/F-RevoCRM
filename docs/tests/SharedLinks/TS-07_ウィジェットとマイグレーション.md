# TS-07 ダッシュボードのウィジェットとマイグレーション

対象:

- `modules/Home/dashboards/SharedLinks.php`、`layouts/v7/modules/Home/dashboards/SharedLinks*.tpl`
- `modules/Home/views/DashBoard.php`（JS・CSS の読み込み）、`SharedLinksWidget.js`（枠の高さ・メニュー）、`<shared-links-widget>`
- `setup/migration/scripts/20261106093622_add_shared_links_widget.php`

## 1. 期待される振る舞い（仕様）

| # | 仕様 | 仕様書 |
|---|---|---|
| S-01 | ホームのダッシュボードの「ウィジェットの追加」に、作ったウィジェットが見出しで出る。同じウィジェットは 1 つのタブに 1 個まで（TS-08） | 3.2 |
| S-02 | ウィジェットの見出しは、管理画面で付けた見出し | 3.2 |
| S-03 | 表示できるリンクを並び順で表示する。説明があればタイトルの下に改行を保って出す | 3.2 |
| S-04 | 表示できるリンクが無いときは「共有リンクが登録されていません」。管理者には設定画面へのリンクも出す | 3.2 |
| S-05 | 更新ボタンで最新の内容を読み直す | 3.2 |
| S-06 | ダッシュボードで枠の調整の JS・CSS を読み込む | 8 |
| S-06b | ウィジェットを大きくすると中身の高さも合わせ、スクロールバーが残らない | 3.2 |
| S-07 | マイグレーションはテーブル 4 つ（`utf8mb4_general_ci`）・最初のウィジェット「共有リンク」・設定メニューを用意する。何度実行しても重複しない（ウィジェットがあれば最初のウィジェットを作らない） | 7.4 |
| S-08 | `vtiger_links_seq` が最大 ID より遅れていても、採番をそろえてウィジェットを登録できる | 7.0 |
| S-09 | 空の DB からの新規インストールでも、このマイグレーションを含めて完走する | 7.4 |
