# TS-03 パラメータの値の解決と URL の組み立て

対象:

- `Settings_SharedLinks_Rules_Model::resolveParams()` / `buildGetUrl()` / `fullName()` / `isInsertableUserField()`
- `Settings_SharedLinks_Module_Model::getInsertableUserFields()` / `getVisibleLinksForCurrentUser()`

## 1. 期待される振る舞い（仕様）

| # | 仕様 | 仕様書 |
|---|---|---|
| S-01 | 固定値はそのまま送る。`{user.email1}` のような文字列も置き換えない | 4.1 |
| S-02 | ユーザー情報は、見ている本人の、DB に保存されている値を送る（表示用の形式に変換しない） | 4.1 |
| S-03 | 「ユーザー ID」はユーザーの ID、「氏名（姓 名）」は姓と名を半角スペースでつないだもの。片方が空なら空でないほうだけ | 4.2 |
| S-04 | 保存後に項目が削除された・差し込めなくなったときは空文字を送る | 4.1 |
| S-05 | 差し込める項目は、ユーザーの項目のうちパスワード・認証用・テキストに向かない項目と uitype 99 を除いたもの（カスタム項目を含む）。非表示（presence=1）の項目は含めない | 4.2 |
| S-06 | GET は、URL の既存のクエリ文字列の後ろにパラメータを足す。同じ名前でも上書きしない。フラグメント（#以降）は最後へ付け直す | 7.2 |
| S-07 | GET のパラメータは名前・値とも RFC 3986 でエンコードする（空白は `%20`） | 7.2 |
| S-08 | POST は URL をそのままにし、解決したパラメータを送信内容として渡す | 3.3 |

### DT-4: GET の URL

| 条件 | R1 | R2 | R3 | R4 | R5 | R6 |
|---|---|---|---|---|---|---|
| パラメータがある | − | ✓ | ✓ | ✓ | ✓ | ✓ |
| URL に `?` がある | * | − | ✓ | ✓（末尾が `?`） | ✓（末尾が `&`） | ✓ |
| URL に `#` がある | * | − | − | − | − | ✓ |
| **結果** | URL をそのまま | `?` で足す | `&` で足す | そのまま足す | そのまま足す | `#…` の前に足す |
| ケース | TC-RES-030 | TC-RES-031 | TC-RES-032 | TC-RES-033 | TC-RES-034 | TC-RES-035 |
