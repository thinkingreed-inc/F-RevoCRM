# TS-01 入力の検証

対象:

- サーバー: `Settings_SharedLinks_Rules_Model::normalize()` / `validate()`（`modules/Settings/SharedLinks/models/Rules.php`）
- 画面: `validateSharedLink()` / `toPayload()`（`assets/react-web-components/src/components/SharedLinks/utils/sharedLinkForm.ts`）

画面とサーバーは同じ規則で検証する（エラーのキーと言語ファイルのキーも同じ）。
画面の検証は使い勝手のため、サーバーの検証は改ざんされた要求を防ぐため。両方をテストする。

## 1. 期待される振る舞い（仕様）

| # | 仕様 | 仕様書 |
|---|---|---|
| S-01 | タイトルは必須。前後の空白を除いて判定し、100 文字まで（文字数はコードポイントで数える） | 3.1 |
| S-02 | URL は必須で 2000 文字まで。scheme が `http` / `https`（大文字小文字を問わない）で、host があること | 3.1, 6.1 |
| S-03 | 説明は任意で 500 文字まで | 3.1 |
| S-04 | メソッドは `GET` / `POST` のみ。小文字で来ても大文字にそろえる | 3.1, 6.1 |
| S-05 | 開き方は `tab` / `window` のみ。`window` のときは幅・高さが 200〜4000 の整数で必須。`tab` のときは幅・高さを捨てる（NULL） | 3.3, 6.1 |
| S-06 | パラメータは 20 行まで。名前は前後の空白を除いて必須・100 文字まで | 3.1 |
| S-07 | 値の種類は `fixed` / `user` のみ。固定値は空でもよく 1000 文字まで（前後の空白も値として残す）。ユーザー情報は項目の選択が必須で、差し込める項目だけ選べる | 3.1, 4 |
| S-08 | 公開範囲は `all` / `targets` のみ。`all` のときは対象を捨てる。`targets` のときは対象が 1 件以上必要 | 3.4 |
| S-09 | 対象の種類は `Users` / `Groups` / `Roles` / `RoleAndSubordinates` のみ。ID は空でないこと。同じ対象（種類と ID が同じ）は重ねられない。「役割」と「役割と下位」は別の対象 | 3.4 |
| S-10 | 対象は存在すること。ユーザーは有効なユーザーだけを新しく選べるが、保存済みの対象は無効になっていても残せる | 3.4 |
| S-11 | 有効（active）を省略したら有効、リファラーを送らない（noreferrer）を省略したら送る | 3.1, 5 |
| S-12 | 想定外の型（配列でない行・文字列でない値）は落とす・空文字にする。エラーで止めず、検証で弾く | 6.1 |
