# TS-01 営業日・休祝日の共通基盤

対象:

- `include/utils/BusinessDay.php` (`FR_BusinessDay`)
- `include/utils/JapaneseHolidays.php` (`FR_JapaneseHolidays`)

## 1. 期待される振る舞い（仕様）

### 1.1 `FR_BusinessDay`

| # | 仕様 |
|---|---|
| S-01 | 週休の曜日は `vtiger_holiday_settings.weekly_holidays` を最優先で使う |
| S-02 | 設定テーブル／行が無い場合は `$GLOBALS['business_week_holidays']`（`config.customize.php`）を使う |
| S-03 | いずれも無い場合の既定は土日（`[0, 6]`） |
| S-04 | 週休の曜日は 0〜6 の整数に正規化し、範囲外・非数値は捨て、重複を除き昇順にする |
| S-05 | マスタに `day_type = 'holiday'` で登録された日は休日 |
| S-06 | マスタに `day_type = 'workday'` で登録された日は、週休曜日であっても**営業日**（休日出勤日） |
| S-07 | マスタ未登録の日は、週休曜日かどうかで判定する |
| S-08 | `addBusinessDays($d, $n)` は起算日を含めず、`$n` 営業日後を返す |
| S-09 | `$n` が負数なら過去方向に数える |
| S-10 | `$n` が 0 なら起算日をそのまま返す（休日でも変換しない） |
| S-11 | `nextBusinessDay($d)` は**当日を含めて**最初の営業日を返す |
| S-12 | `countBusinessDays($from, $to)` は両端を含む営業日数を返す。`from > to` なら入れ替える。**期間の長さに上限を設けない** |
| S-13 | 空・`null`・`0000-00-00` は「未入力」として扱い、計算系は `null`（`countBusinessDays` は `0`、判定系は `false`）を返す |
| S-13b | 日付として解釈できない値・実在しない日付（2月30日など）は `InvalidArgumentException` を投げる。<br>黙って別の日へ繰り上げない |
| S-14 | 営業日の**探索**（`addBusinessDays` / `nextBusinessDay`）は `MAX_SEARCH_DAYS`(3650) で打ち切り、無限ループにならない |
| S-15 | マスタは年単位でまとめて読み込み、同一リクエスト内でキャッシュする。`clearCache()` で破棄できる |
| S-16 | 設定テーブルが未作成（マイグレーション前）でもエラーにならず既定値で動作する |

### 1.2 `FR_JapaneseHolidays`

| # | 仕様 |
|---|---|
| S-20 | `forYear($y)` は固定祝日・ハッピーマンデー・春分／秋分を返す |
| S-21 | 祝日が日曜と重なった場合、直後の「祝日でない日」を振替休日にする（連続する祝日は飛ばす） |
| S-22 | 前後を祝日に挟まれた平日は「国民の休日」にする（日曜は対象外・年跨ぎは対象外） |
| S-23 | 2020年・2021年はオリンピック特例（海の日／スポーツの日／山の日の移動）を反映する |
| S-24 | 対応開始年は 2020年（`SUPPORTED_FROM_YEAR`）。それ以前は計算対象外 |
| S-25 | `parseOfficialCsv()` は内閣府公表CSV（Shift_JIS）を UTF-8 に変換して解析する |
| S-26 | CSV の「休日」は前後の祝日から `振替休日` / `国民の休日` に読み替える |
| S-27 | 解析できない・1件も取れない場合は例外を投げる（黙って空を返さない） |

## 2. デシジョン表

### DT-1: `FR_BusinessDay::isHoliday()` / `isBusinessDay()`

| 条件 | R1 | R2 | R3 | R4 | R5 | R6 |
|---|---|---|---|---|---|---|
| 空・`null`・`0000-00-00`（未入力） | ✓ | − | − | − | − | − |
| 日付として解釈できる・実在する | * | − | ✓ | ✓ | ✓ | ✓ |
| マスタに `workday` で登録 | * | * | ✓ | ✓ | − | − |
| マスタに `holiday` で登録 | * | * | − | − | ✓ | − |
| 週休曜日である | * | * | ✓ | − | * | ✓ |
| **isHoliday** | false | 例外 | false | false | true | true |
| **isBusinessDay** | true | 例外 | true | true | false | false |
| 対応ケース | TC-BD-013 | TC-BD-013b | TC-BD-006 | TC-BD-007 | TC-BD-004 | TC-BD-002 |

> R1（未入力）は「休日ではない」として `false` を返す。呼び出し側が未入力を分岐できるようにするための仕様。
> R2（不正な日付）は `InvalidArgumentException`。誤った日付で計算結果が静かにずれるのを防ぐ。

### DT-2: `FR_BusinessDay::getWeeklyHolidays()` の値の決定

| 条件 | R1 | R2 | R3 |
|---|---|---|---|
| `vtiger_holiday_settings` テーブルが存在し `weekly_holidays` 行がある | ✓ | − | − |
| `$GLOBALS['business_week_holidays']` が配列で存在 | * | ✓ | − |
| **結果** | 設定テーブルの値 | config の値 | `[0, 6]` |
| 対応ケース | TC-BD-020 | TC-BD-021 | TC-BD-022 |

> 設定行の値が空文字の場合、R1 が成立し `[]`（週休なし）になる。R2/R3 にフォールバックしない。

### DT-3: `FR_JapaneseHolidays` の振替休日／国民の休日

| 条件 | R1 | R2 | R3 | R4 | R5 |
|---|---|---|---|---|---|
| 当日が祝日 | ✓ | ✓ | − | − | − |
| 当日が日曜 | ✓ | − | ✓ | − | − |
| 前日が祝日 | * | * | * | ✓ | ✓ |
| 翌日が祝日 | * | * | * | ✓ | − |
| **結果** | 直後の非祝日を振替休日にする | 何もしない | 何もしない | 国民の休日 | 何もしない |
| 対応ケース | TC-JH-010 | TC-JH-001 | TC-JH-013 | TC-JH-011 | TC-JH-012 |

### DT-4: `parseOfficialCsv()` の1行の扱い

| 条件 | R1 | R2 | R3 | R4 | R5 |
|---|---|---|---|---|---|
| 行が空 | ✓ | − | − | − | − |

| 名称が空でない | * | * | − | ✓ | ✓ |
| 日付が `YYYY/M/D` または `YYYY-M-D` | * | * | * | − | ✓ |
| **結果** | スキップ | スキップ | スキップ | スキップ（ヘッダー行を含む） | 取り込む |

## 3. 境界値・同値分割

### BV-1: `normalizeWeekdays()` の入力値

| 入力 | 分類 | 期待 |
|---|---|---|
| `-1` | 下限外 | 除外 |
| `0` | 下限 | 採用（日曜） |
| `6` | 上限 | 採用（土曜） |
| `7` | 上限外 | 除外 |
| `'3'` / `' 3 '` | 数値文字列・前後空白 | 採用（3） |
| `3.7` | 小数 | `is_numeric` 成立 → `(int)3` として採用 ⚠️ 要確認 |
| `'x'` / `null` | 非数値 | 除外 |
| `[6,0,6]` | 重複・逆順 | `[0,6]`（重複除去・昇順） |
| `''` | 空文字 | `[]`（週休なし） |
| `'0,6'` | カンマ区切り文字列 | `[0,6]` |
| `[]` | 空配列 | `[]`（週休なし＝全日営業日） |
| `[0,1,2,3,4,5,6]` | 全曜日 | `[0..6]`（全日休日） |

### BV-2: `addBusinessDays()` の日数

| 入力 | 期待 |
|---|---|
| `0` | 起算日をそのまま返す（休日でも変換しない） |
| `1` | 次の営業日 |
| `-1` | 前の営業日 |
| `7`（既定） | 起算日から7営業日後 |
| 全曜日が週休の状態で `1` | 3650回探索して `null` |
| 不正な日付 | `null` |

### BV-3: 日付文字列

| 入力 | 期待 |
|---|---|
| `''` / `null` / `'0000-00-00'` / `'0000-00-00 00:00:00'` / 空白のみ | `null`（未入力） |
| `'2035-01-01'` | そのまま |
| `'2035/01/01'` | `2035-01-01`（スラッシュ区切りも受理） |
| `'2026-02-28'` | そのまま（うるう年でない2月の末日） |
| `'2024-02-29'` | そのまま（うるう年） |
| `'2026-02-30'` | **`InvalidArgumentException`**（実在しないため。繰り上げない） |
| `'2035-13-01'` / `'2035-01-32'` | `InvalidArgumentException` |
| `'abc'` | `InvalidArgumentException` |

### BV-4: `countBusinessDays()` の期間

| 入力 | 期待 |
|---|---|
| `from == to`（営業日） | 1 |
| `from == to`（休日） | 0 |
| `from > to` | 入れ替えて計算（対称） |
| 3651日を超える期間（例: 2030-01-01〜2045-01-01） | 打ち切らず正しく数える（週休のみなら 3914） |
| 週休なしの1年（2035-01-01〜2035-12-31） | 365 |
| 週休が土日の1年（同上） | 261 |
| 期間内にマスタの `holiday`（平日）が n 件 | 週休ベースの日数から n を引く |
| 期間内にマスタの `workday`（週休日）が n 件 | 週休ベースの日数に n を足す |
| 期間内にマスタの `holiday`（既に週休日） | 二重に引かない |

### BV-5: `forYear()` の年

| 入力 | 期待 |
|---|---|
| 2019 | 改正前の祝日を含まないため利用対象外（`SUPPORTED_FROM_YEAR` 未満）。関数自体は値を返す |
| 2020 | 特例年（海の日 7/23・スポーツの日 7/24・山の日 8/10）／18件 |
| 2021 | 特例年（海の日 7/22・スポーツの日 7/23・山の日 8/8）／17件 |
| 2026 | 通常年／18件（国民の休日 9/22 を含む） |
| 2099 | 春分・秋分の近似式の有効上限 |
| 2100 | 近似式の適用外。値は返るが正しさは保証されない ⚠️ 要確認 |
