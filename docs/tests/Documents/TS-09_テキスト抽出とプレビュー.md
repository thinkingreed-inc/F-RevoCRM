# TS-09 テキスト抽出・プレビュー・ダウンロード

対象:

- `modules/Documents/utils/TextExtractor.php`
- `modules/Documents/schema/reindex_documents.php`
- `modules/Documents/actions/PreviewContent.php`
- `modules/Documents/actions/DownloadVersion.php`
- `modules/Documents/models/Record.php`（`downloadFile()` / `streamFile()`）
- React: `FilePreviewRenderer.tsx` / `DocumentsPreviewPanel.tsx` / `DocumentsPreviewView.tsx`
- 同梱ライブラリ: `public/libraries/jquery/luckysheet` / `pptxjs`

## 1. 期待される振る舞い（仕様）

### 1.1 テキスト抽出（全文検索用）

| # | 仕様 |
|---|---|
| S-01 | 内部ファイルの登録・差替え時に本文テキストを抽出し `vtiger_notes.indexed_content` に保存する |
| S-02 | 対応形式は PDF / DOCX / XLSX / PPTX / プレーンテキスト（txt, csv, log, md, json, xml, html, htm） |
| S-03 | 形式は拡張子と MIME タイプの両方で判定する |
| S-04 | 抽出テキストは空白・改行を1つのスペースに正規化し、前後を除去する |
| S-05 | 抽出テキストは 1,000,000 文字で切り詰める |
| S-06 | 抽出に失敗しても例外にせず `null` を返し、ドキュメントの保存は成功させる |
| S-07 | 未対応形式は `null`（エラーにしない） |
| S-08 | 抽出はシート・スライドの数で打ち切らない。ZIP 内の実在する項目を列挙するため、<br>連番が飛んでいるファイル（sheet1, sheet3 など）でも取りこぼさない |

### 1.2 Office プレビュー（サーバー側変換）

| # | 仕様 |
|---|---|
| S-10 | XLSX / PPTX / DOCX を HTML に変換して返す |
| S-11 | 未対応形式は `LBL_PREVIEW_UNSUPPORTED_FORMAT` を返す |
| S-12 | ファイルが存在しない・読めない場合は明示的なエラーを返す |
| S-13 | セルやテキストは HTML エスケープして出力する（XSS を作らない） |
| S-14 | 表示件数に上限を設ける（XLSX は5シート・1シートあたり500行、PPTX は50スライドまで） |
| S-15 | 上限に達して省略した場合は、その旨を画面に表示する（黙って切り捨てない） |
| S-16 | シート・スライドは ZIP 内の実在する項目を列挙する（連番が飛んでいても取りこぼさない） |

### 1.3 ダウンロード

| # | 仕様 |
|---|---|
| S-20 | ファイルはストリーミングで出力し、全体をメモリに載せない（大容量対応） |
| S-21 | `Content-Length` を返し、ダウンロードの進捗が分かる |
| S-22 | 大容量でも実行時間制限で中断しない |
| S-23 | 過去バージョンをバージョン番号指定でダウンロードできる |
| S-24 | ダウンロードは監査ログに記録する |
| S-25 | 外部URL（`filelocationtype='E'`）は本処理の対象外 |

## 3. 境界値・同値分割

### BV-1: 抽出テキスト長（`MAX_TEXT_LENGTH = 1,000,000`）

| 入力 | 期待 |
|---|---|
| 0文字（空ファイル） | `''`（`null` ではない）。保存される |
| 999,999文字 | そのまま |
| 1,000,000文字 | そのまま（境界） |
| 1,000,001文字 | 1,000,000文字に切り詰め |
| マルチバイト | `mb_strlen`/`mb_substr` により**文字数**基準（バイト数ではない） |

### BV-2: シート／スライド数

| 対象 | 境界 | 期待 |
|---|---|---|
| XLSX 抽出 | 21シート / 100シート | **すべて抽出**（上限なし。最終的に MAX_TEXT_LENGTH で切り詰め） |
| XLSX 抽出 | sheet1, sheet3（連番が飛ぶ） | 両方とも抽出される |
| PPTX 抽出 | 101スライド | **すべて抽出** |
| PPTX 抽出 | slide1, slide3（連番が飛ぶ） | 両方とも抽出される |
| XLSX プレビュー | 5シート | すべて表示。省略の通知なし |
| XLSX プレビュー | 6シート | 5シートまで表示し、`LBL_PREVIEW_TRUNCATED_SHEETS`（表示数と総数）を表示 |
| XLSX プレビュー | 500行 | すべて表示。省略の通知なし |
| XLSX プレビュー | 501行 | 500行まで表示し、`LBL_PREVIEW_TRUNCATED_ROWS` を該当シートの直後に表示 |
| PPTX プレビュー | 50スライド | すべて表示。省略の通知なし |
| PPTX プレビュー | 51スライド | 50枚まで表示し、`LBL_PREVIEW_TRUNCATED_SLIDES` を表示 |
| プレビュー | sheet1, sheet3（連番が飛ぶ） | 両方とも表示され、シート名の対応がずれない |

### BV-3: Excel 列参照（`colToIndex`）

| 入力 | 期待 |
|---|---|
| `A1` | 0 |
| `Z1` | 25 |
| `AA1` | 26 |
| `AZ1` | 51 |
| `BA1` | 52 |
| `XFD1`（Excel の最大列） | 16383 |
| `1`（列指定なし） | 0（フォールバック） |
| `''` | 0 |

### BV-4: ファイルサイズ（ダウンロード）

| 入力 | 期待 |
|---|---|
| 0バイト | 空ファイルがダウンロードされる（エラーにしない） |
| 1MB 未満 | 1回の `fread` で送出 |
| 1MB ちょうど | 送出できる（読み出し単位の境界） |
| 2GB | メモリ超過・タイムアウトせず完走する |
| ファイルなし | `streamFile()` が `false`。ヘッダーを出力しない |

### BV-5: ダウンロードファイル名

| 入力 | 期待 |
|---|---|
| `report.pdf` | `filename="report.pdf"; filename*=UTF-8''report.pdf` |
| `テスト資料.pdf` | `filename*` に percent-encoding で出力され、文字化けしない |
| `a"b.pdf` | 二重引用符が除去され `filename="ab.pdf"`。`filename*` には元の名前が入る |
| `a\b.pdf` | バックスラッシュが除去される |
| `a\r\nX-Evil: 1.pdf` | 改行が除去され、**別ヘッダーが注入されない** |
| 名前がすべて除去される場合 | `filename="download"` にフォールバック |
| MIME タイプに改行を含む値 | 改行が除去される |
| HTML エンティティを含む名前 | `html_entity_decode` により元の文字に戻る |
